# Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and Bootstrap 5.

## Features

- Responsive design that works on all devices
- Modern and clean UI
- Smooth scrolling navigation
- Project portfolio section
- Contact information and social links
- Bootstrap 5 framework

## Sections

- **Home**: Introduction and social media links
- **About**: Information about skills and experiences
- **Portfolio**: Showcase of projects with images and descriptions
- **Contact**: Contact information and links to social profiles

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome icons

## How to View

Simply open the `index.html` file in your web browser, or you can use a local server:

```bash
# For Python 2
python -m SimpleHTTPServer

# For Python 3
python -m http.server 8000
```

Then visit `localhost:8000` in your web browser.

## Deployment

This project is deployed using Netlify.
